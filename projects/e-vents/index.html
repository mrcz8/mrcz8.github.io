Case study

E-vents

An event management app that helps organizers schedule events, work with suppliers, and manage bookings in one place.

Role:
Full-Stack Developer

The client and the problem

Event organizers needed one place to plan events, find and vet suppliers, and keep track of bookings and leads.

What I built

The E-vents application is designed for event organizers to streamline the planning and management of events. It provides tools for scheduling, attendee management, and event coordination, helping organizers efficiently track and execute events from start to finish.

  • Designed a scheduling engine that handles concurrent event bookings without conflicts
  • Built real-time attendee management with check-in tracking and status updates
  • Deployed with Docker and Nginx for reliable, zero-downtime production hosting

Tech stack

  • PHP
  • Laravel
  • Vue
  • NuxtJS
  • Tailwind
  • PostgreSQL
  • Docker
  • Nginx
