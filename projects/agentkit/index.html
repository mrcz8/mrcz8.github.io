Case study

agentkit – Local Multi-Agent Workshop

A learning project where you draw a team of AI agents, give it a task, and watch every agent, tool call, and reply as it runs.

Role:
Personal learning project
Source code:
View on GitHub

Why I built it

This is a personal learning project, not client work. I wanted to understand how AI agents work underneath the frameworks, so I wrote the agent loop twice, once by hand with plain HTTP calls and once on LangGraph and LangChain. Both engines run the same agents and tools, so I could compare them side by side.

What I built

A local web app for building and running teams of AI agents. You add agents on a canvas, connect them so one can delegate to another, group them into departments, or start from one of five templates. Every run is shown as a tree of agents where you can read each task, model turn, tool call, and report. It runs on local models through Ollama, so it needs no API keys and no code leaves the machine.

  • Wrote the agent loop twice, by hand and on LangGraph, with both engines running the same agent files and tools and emitting the same events
  • Built delegation between agents, fixed processes that run agents in a set order, and checker agents that review another agent's work for up to three attempts
  • Added approvals for delegations and risky commands; on the LangGraph engine a delegation waiting for approval is saved to SQLite and resumes after a restart
  • Built the Design and Run views with React and React Flow, with each run streamed live from a FastAPI backend
  • Documented the differences between the two engines, with real test runs, and the path from one raw HTTP request to the finished app
